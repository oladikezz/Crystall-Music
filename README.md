# Crystall-Music 

Crystall Music — минималистичный Android плеер в дизайне Pure Liquid Glass (iOS 27 / Apple Music).

## Возможности
- 💎 **Pure Liquid Glassmorphism**: матовое полупрозрачное стекло, сквиркл-обложки, зеркальные грани, парящий Dynamic Island Mini-Player и плавающий Navigation Dock.
- 🎵 **Автономный стриминг**: прямое воспроизведение оригинальных потоков YouTube Music без сторонних серверов.
- 📥 **Офлайн-скачивание**: сохранение музыки на устройство в один тап для прослушивания без интернета.
- ⚡ **Живой эквалайзер**: анимированные стеклянные звуковые волны в реальном времени.
- 📋 **Импорт плейлистов**: моментальный перенос плейлистов из YouTube Music.
